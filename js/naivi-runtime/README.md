# @naivi/runtime

Vue Vapor runtime adapter for **naivi** — bridges a DOM-style API to the blitz renderer API (wasm and native desktop hosts).

Subpath entry points:

- `@naivi/runtime/vue-vapor` — the Vue Vapor adapter used by demo `main.ts`
- `@naivi/runtime/desktop-main` — desktop main-process API (`app` / `NaiveWindow`), aliased by the CLI
- `@naivi/runtime/naive-dom`, `/wasm-types`, `/placeholder-text` — lower-level building blocks
