# @naivi/protocol

Single source of truth for the **naivi** bridge protocol — event kinds and wire tables shared by the JS runtime (`import`) and by `naivi-dom`'s build script (literal-table parse).

> ⚠️ Breaking changes here must be coordinated with the Rust side (`packages/naivi-dom`), which parses the same literal tables.
