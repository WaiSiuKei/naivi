# @naivi/cli

CLI for **naivi** — build and serve Vue Vapor apps on the [blitz](https://github.com/DioxusLabs/blitz) browser engine.

```bash
npx nv web          # run a demo in the wasm build
npx nv desktop      # run a demo in the native desktop window
npx nv wasm         # serve the wasm host
```

The CLI is prebuild-free: it runs its TypeScript source directly via `tsx`. Requires Node.js >= 24.
